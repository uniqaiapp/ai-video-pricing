AI video cost per second for Kling 3.0, Veo 3 and 3.1, Runway Gen-4.5, Luma Ray3.2, Pika, MiniMax Hailuo and H3, Seedance via BytePlus, Higgsfield, Google Flow, the Gemini API and UniqAI, checked on 2026-10-28, with a source URL on every row. Vendors sell plans and credits, not seconds, so the table divides what you pay by the seconds you get and shows the arithmetic in the cell. The data is JSON and CSV under CC BY 4.0; a Node CLI with no dependencies filters it, recomputes it, prices your own plan, and lists rows that are overdue for a recheck. The long-form explainer with the same numbers is on [uniqai.app](https://uniqai.app/video/ai-video-cost-per-second?utm_source=github&utm_medium=readme&utm_campaign=ai-video-pricing).

| **One formula, shown** | **Vendor pages only** | **Stale rows get flagged** |
|:---|:---|:---|
| `(credits per clip × $ per credit) ÷ seconds delivered`, printed next to every number, recomputed by the CLI, never typed by hand. | Every row links the vendor's own pricing page and the date it was read. Prices shown only inside an app say "not published", not a guess. | `avp stale` lists rows older than 30 days; a monthly GitHub Action turns that into a checklist issue. |

## Quickstart

```bash
git clone https://github.com/uniqaiapp/ai-video-pricing && cd ai-video-pricing
node scripts/avp.mjs cheapest --resolution 720p
node scripts/avp.mjs quote --plan-price 15 --credits 625 --credits-per-second 12
```

The first command prints the five cheapest published 720p rows with their formulas; the second turns a plan ("$15 for 625 credits, 12 credits per second") into $0.288 per second, $0.024 per credit and $17.28 per minute. Node 18 or newer, nothing to install.

## How it works

1. `data/prices.json` holds one row per service, model and setting, with the inputs a vendor actually publishes: plan price and credits, credits per clip or per second, seconds delivered, resolution, audio, or a direct per-clip, per-second or per-token price. The field docs are in [`data/schema.json`](data/schema.json).
2. `node scripts/avp.mjs recompute --write` fills `usd_per_second` from those inputs with one formula per billing kind. `validate` fails if a stored value differs from the recomputed one, if a URL is malformed, a date is not real, or a published row lacks the inputs its billing kind needs.
3. `export`, `readme --write` and `scripts/examples.mjs` regenerate the CSV, this README's table and the files in `examples/`. Tests compare each against the data byte for byte, so a number cannot change in one place only.
4. `stale --days 30` lists rows older than 30 days grouped by source page; `.github/workflows/price-recheck.yml` runs it on the first of every month and opens a checklist issue.

```
data/prices.json ──recompute──▶ usd_per_second ──export──▶ data/prices.csv
        │                                          ──readme──▶ README.md (this table)
        │                                          ──examples──▶ examples/*
        └──stale──▶ price-recheck issue (monthly)
```

## Usage

```bash
node scripts/avp.mjs table --max 0.10 --published --format text   # everything at or under 10 cents
node scripts/avp.mjs model "Kling 3.0"                             # the same model through every door
node scripts/avp.mjs cheapest --audio yes --brief                  # cheapest rows whose price includes audio
node scripts/avp.mjs table --door api --format csv > api.csv       # developer APIs only, as CSV
node scripts/avp.mjs quote --plan-price 30 --credits 10000 --credits-per-clip 100 --seconds 5
node scripts/avp.mjs quote --clip-price 0.28 --seconds 6
node scripts/avp.mjs stale --days 30                               # rows due for a recheck
node scripts/avp.mjs validate                                      # schema + arithmetic, exit 1 on errors
node scripts/avp.mjs --help
```

Filters: `--service`, `--model`, `--maker`, `--door app|api`, `--resolution 720p`, `--audio yes|no`, `--max 0.10`, `--published`. Sort with `--sort price|service|model|checked` and `--desc`; output with `--format md|text|csv|json`. The data is plain JSON, so you can also skip the CLI: `JSON.parse(fs.readFileSync("data/prices.json"))` or `pandas.read_csv("data/prices.csv")`.

## Keeping it fresh

Prices move monthly. [`.github/workflows/price-recheck.yml`](.github/workflows/price-recheck.yml) runs on the first of each month, lists every row older than 30 days grouped by source page, and opens one `price-recheck` issue (or comments on the open one) with a checklist. A maintainer re-reads each page, updates the inputs and `checked_on`, and runs:

```bash
node scripts/avp.mjs recompute --write && node scripts/avp.mjs validate
node scripts/avp.mjs export && node scripts/avp.mjs readme --write && node scripts/examples.mjs
node tests/run.mjs
```

To reuse the reminder in your own data repo, copy the workflow and replace the two `stale` lines with any command that prints your overdue rows as Markdown.

## Limits and honesty

- Every number here is either read from the linked vendor page on the date shown or computed from such numbers by the formula in the cell. Nothing is estimated. A vendor that hides its price gets a `not_published` row.
- The dataset prices paid output on standard monthly billing. Free daily credits, promotional first months, annual discounts, watermarks, commercial-licence tiers, "unlimited" modes, rollover and API minimums change the effective price for some users; they are in `notes` and in the [methodology](references/methodology.md), not in the number.
- UniqAI's own rows follow the same rule as everyone else's: the two packs anyone can buy without a plan, plus the largest packs as the floor. UniqAI is one of the cheaper doors for Kling 3.0 and Wan 2.5 and one of the pricier ones for Veo 3; the table says so.
- Row, service and model counts in this README come from `node scripts/avp.mjs validate` (`ok: 69 rows, 64 published`) and the examples. There are no usage, download or popularity numbers here because we do not have honest ones.
- Resolution labels are the vendor's and are not normalised. The dataset is USD and English-language, and covers the vendors listed above; it does not claim to be complete.

## FAQ

<details>
<summary><b>What is the cheapest AI video generator per second?</b></summary>

On the rows checked 2026-10-28, Seedance 1.0 Pro Fast through the BytePlus ModelArk API at 480p ($0.05 per 5-second clip, $0.010 per second). At 720p the floor is $0.020 to $0.030 (Seedance 1.0 Pro Fast, Gemini Omni Flash in Google Flow). Run `node scripts/avp.mjs cheapest --resolution 720p` for the current list with formulas.

</details>

<details>
<summary><b>How much does Kling 3.0 cost per second?</b></summary>

It depends on the door: $0.080 in UniqAI (5 s clip, 1,000-Gem pack), $0.090 through Runway's API without audio, $0.147 in Luma at 1080p with audio, $0.400 at 4K on Kling's own Standard plan. Kling's app does not publish its 720p and 1080p credit costs outside the generation panel. `node scripts/avp.mjs model "Kling 3.0"` prints all of it.

</details>

<details>
<summary><b>Why is the same model priced so differently?</b></summary>

Plan arithmetic. A $30 plan with 10,000 credits and a $15 plan with 625 credits cannot be compared until you know what one credit buys for that model at that resolution. Resellers also add minimums (Runway's 56 to 80 credits per generation) and bundle audio differently. Dividing by delivered seconds is the only way to put them side by side, and the clip column tells you when the comparison is still unfair.

</details>

<details>
<summary><b>Does OpenAI still sell Sora?</b></summary>

No. The Sora app closed on 2026-04-26 and the Videos API with sora-2 and sora-2-pro was removed on 2026-09-24; OpenAI's deprecations page lists no replacement video model, so the dataset carries a `discontinued` row rather than a price.

</details>
